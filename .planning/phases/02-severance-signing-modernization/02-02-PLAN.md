Build the permanent private-API regression gate (INFRA-05): a strings-based binary scanner with a TDD-validated marker list scoped to this phase's REMOVED symbols only, wired into a GitHub Actions workflow that scans both binaries every push.

Scope decision (encoded from resolved NOTES.md and PROJECT.md Key Decisions by plan 02-01): the gate fails on MediaRemote, BackBoardServices brightness, SpringBoard lock/port, and TrollStore entitlement markers — the things Phase 2 removes. Purpose: Every subsequent phase's CI catches private-API regression before upload, per the ROADMAP note that this gate is permanent. This plan runs in wave 1 deliberately — Task 2's proof-of-detection needs the app binary to still contain the pre-severance markers, so plan 02-03 (the Swift-layer severance) is sequenced after this one.
Output: Tested scan script + CI workflow.

Expected CI behavior: pushes made between this plan and plan 02-03's completion fail the workflow (markers still in the binary) — that is the gate working, not a plan failure; the phase-close green run happens after 02-03/02-04 land.
