<objective>
Raise the deployment target to iOS 16.0, remove the orphaned Dynamic SPM package, and make hook behavioral re-validation visible (INFRA-04): extend the existing Debug screen with a hook-verification section reporting live runtime status of every surviving hook and injected script at the new floor.

Pitfall 5 is the failure mode this plan is built around: hooks install only when method type encodings match exactly, and AutoHook communicates failure via NSLog only — a raised target can silently disable the AutoResize/HideScrollBar hooks and the keyboard's private API with no build error. The debug screen turns silent failure into a visible checklist; the on-simulator verification step runs the app at the iOS 16 runtime and reads that checklist.

Script re-validation (ad block, SponsorBlock, age-restriction bypass at ROADMAP success criterion 3) rides the same screen: per-script rows force each script on via the applyConfiguration path that plan 02-03 extracted, so a tester can toggle one script and see the webview reload with it active.

Purpose: The modernized floor is behaviorally verified, not just compiled, and every later phase inherits a working hook-verification surface.
Output: iOS 16 project, SPM-free, extended Debug screen, runtime-verified hooks.
</objective>
