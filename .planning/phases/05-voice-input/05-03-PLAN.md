## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Siri utterance → intent parameter | spoken input crosses from Siri into the app process as an open String — untrusted user input into the funnel |
| intent → shared funnel | the intent is a fourth funnel head; it must not bypass validation or the coordinator |
| build-time extractor → phrases | phrase legality is enforced by the toolchain, not runtime checks |

| T-05-SC | Tampering | package installs | low | accept | AppIntents is a system framework; no packages |
